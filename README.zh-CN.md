# ACNH Mobile

当前版本：**0.1.21（构建34）**。两个无游戏空壳版本见 [Releases](https://github.com/huajiaoshu520/acnh-mobile/releases)。

- **ACNHMobile-iOS26**：主线版，最低 iOS 26。
- **ACNHMobile-iOS18-compat**：Metal 3 兼容版，最低 iOS 18。

两版保留原定画质与功能；安装下限不代表所有符合条件的设备均已实测。公开 IPA 均为不含游戏的空壳，需要使用者在本地准备自己持有的运行文件。

本候选包含采样器寿命修复，Apple M4 的 Metal API 校验及回归通过。铲头变黄、坑边黑块和手机持续发热/掉帧尚未解决；4/32 MiB 长时间同场景对照未完成，不宣称32 MiB更稳或更凉。

《集合啦！动物森友会》3.0.3 的实验性 iPhone / iPad 原生兼容层，包含 Apple Silicon Mac 调试宿主。基于 D2R Mobile 的公开兼容层，并加入 ACNH 对应的系统服务、图形、输入、存档与资源读取支持。

本仓库提供源码、构建工具、接口说明，并支持自动生成不含游戏的运行空壳。**不提供游戏本体、游戏程序、运行资源、着色器、密钥或存档；仅包含用于识别应用的项目图标。** 这些内容须由使用者从自己持有的游戏文件在本地生成。生成的 IPA 内含使用者自己的游戏程序与翻译着色器，不属于本项目的纯源码发布包。

## GitHub 自动生成空壳

打开 **Actions → Build game-free iOS shell → Run workflow**。完成后从该次运行的 **Artifacts** 下载并解开外层 ZIP，取得两个未签名无游戏空壳 IPA、审计报告和 `SHA256SUMS.txt`。

创建与版本配置相符的 `v*` 标签后，流程会在两版均构建、核验通过后发布一个正式 Release，只附两个空壳 IPA 和共同校验文件。本次 main 首次推入0.1.21/构建34也会自动发布；已有版本不会覆盖。手动运行时两个标签字段均留空则只生成 Actions 附件。流程不接收游戏、key 或 Apple 签名证书。

**空壳不含游戏程序，不能直接玩；只导入 `.data` 也无法启动。** 使用者需在自己的 Apple Silicon Mac 上准备游戏程序和着色器，组装完整 IPA 后签名安装。游戏资源继续从外置 `.data` 直接读取，不解压。

完整步骤、电脑要求和验证范围见[空壳构建与私人组包说明](docs/SHELL.zh-CN.md)。当前不宣称支持 Windows/Linux 一键完成全部游戏准备。

## 在本地构建

在 Apple Silicon Mac 上安装 Xcode、Metal 编译工具、XcodeGen、.NET 10、spirv-cross、zstd 与 Python 3.10+，然后：

```sh
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -r requirements.txt
./setup.sh check
```

按 [构建说明](docs/BUILD.zh-CN.md) 提供自己的解密后 ExeFS / RomFS。脚本不下载游戏或密钥，也不上传这些文件。**不要把以前用于个人测试的整合 IPA 上传到源码仓库。**

## 验证与限制

维护期间已用独立存档副本验证进岛、手动保存与重读、地图、打开邮箱并读信及时间显示。时间转换测试覆盖多个时区；震动和地图状态另有单元/GPU 检查。电脑端测试不等同于手机耗电、温度或马达效果的测量。源码导出报告列出本次实际运行的检查，未完成的全量重建不会标为通过。

提交问题时请提供安装版本、机型、系统版本、复现步骤和已去除个人信息的日志；不要提交游戏文件、密钥或个人存档。

### 安装包版本号

统一修改 `config/version.json`：`version` 是安装列表显示的版本（当前 `0.1.4`），`build` 是内部构建号（当前 `15`，每次重打包递增）。本地 IPA 和 GitHub 空壳自动读取，发布标签应使用对应的 `v0.1.4`。已安装的旧包需重新构建并安装后才显示新版本。
