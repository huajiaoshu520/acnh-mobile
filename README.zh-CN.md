## 下载与使用

[Releases](https://github.com/huajiaoshu520/acnh-mobile/releases) 从 v0.3.90 起仅附带 **LiveContainer + SideStore 联机宿主 IPA**，不再附带空壳或校验文件。

空壳不含游戏程序、游戏数据、转换后的游戏着色器、key、存档或字体。项目图标是唯一的识别图片。空壳不能直接游玩，仅导入 `.data` 也无法启动；需要在电脑上使用自己的游戏程序、官方配套着色器和字体生成私人完整 IPA，再整包签名。

[构建说明](docs/BUILD.md) · [空壳补包说明](docs/SHELL.zh-CN.md)

原来的 `./setup.sh build --patched … --romfs … --shaders … --font … --work … --output …` 用法不变。已有 3.0.3 的 `ACNH-index.data` 和所有编号分卷可继续使用，放在应用的 `Documents/ACNHMobile`，不解压、不并入 IPA。也可以在应用启动时选择对应文件夹。

## 操作

左摇杆移动；工具图标按住滑动选择；手机、表情、背包、拾取、跳跃、返回和互动保持原图标及位置。右侧相机图标拖动调整游戏支持的视角。R 打开聊天后识别输入界面；命名时点击游戏输入框，识别后唤起系统输入法。输入后由用户在游戏里确认，不自动确认不可修改的名字。

拍照获准且成功导出到手机相册后才移除该次应用内照片；拒绝或导出失败时保留在应用内。amiibo 通过用户选择的文件读取；NFC 硬件探测受实际签名宿主权限限制，不能据此保证实体卡可以直接在游戏中使用。

## 本地一键入口

完整下载并解压项目后，双击根目录的「一键生成IPA和数据包.command」「一键生成完整IPA.command」或「一键生成Mac应用.command」。依次选择自己的游戏目录、prod.keys 和成品保存文件夹，脚本便会自动检查并补齐依赖、完成制作；无需输入命令或编辑配置。成品校验成功后自动清理本次制作缓存，保留成品、日志和原始输入。详见 [一键构建说明](docs/ONE-CLICK.zh-CN.md)。

使用 `./setup.sh mac-app` 从自备游戏和 keys 制作完整 `.app`，或复用已有匹配的 Mac 输入。[制作教程](docs/MAC-APP.zh-CN.md)。

### 一键生成外置 DLC

将自己的 DLC NSP 与本体、3.0.3 更新放在同一输入目录。一键工具调用官方提取器，并将 DLC 资源纳入着色器准备；两种 iOS 构建方式都会在 IPA 旁生成 `aoc` 文件夹。将整个 `aoc` 放入手机应用的 `Documents` 后重启；现有 `.data` 仍放在 `Documents/ACNHMobile`，无需因补充 DLC 重做。增加或移除 DLC 会使准备缓存失效，输出的 `aoc` 按完整集合替换，不合并旧文件；无 DLC 时输出空文件夹。Mac 应用构建会包含提取后的 DLC。游戏内容与 keys 不上传公开仓库。

DLC 也可放在 `游戏目录/dlc/` 中，兼容 `DLC` 大写及其内部子目录；该目录只放 DLC，不放本体或更新，不扫描其他构建缓存目录。
