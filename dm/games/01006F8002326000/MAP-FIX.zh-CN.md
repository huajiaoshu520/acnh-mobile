# 动森地图透明度补丁

此目录集中保存本项目现有的地图 alpha-test 补丁，不是 Duo 下屏地图功能。

- `map_alpha.py`：在片元颜色计算完成后执行 NVN alpha test，覆盖提前返回和缺失 alpha 分量的情况。
- `map_alpha.h`：按绘制状态向片元 buffer 30 绑定比较函数和参考值；使用受 fence 保护的 arena，防止后续绘制覆盖前一次状态。
- `game.tsv` 的 `shader_patch` 和 `nvn_draw_patch` 成对启用。没有这两个配置的游戏不做此着色器改写，不绑定 buffer 30，也不启用补丁新增的覆盖判断。

`game.py`、`dmsh_build.py` 和 `nvn_mtl.m` 只保留加载/调用接口。因此渲染器并非与 NX 官方逐字一致。此补丁按动森配置隔离，不宣称只修改地图的某个着色器：它沿用已验证的动态 alpha-test 行为。

关闭对照：同时删除或注释 game.tsv 最后两个补丁配置，再重新生成着色器和编译运行时。不能只关闭一边，也不能用另一配置的缓存重新标记冒充新缓存。补丁源码纳入着色器缓存摘要，修改会触发缓存失效。

整理后的验证：9 项 Python 测试（含未配置游戏不变、成对配置、路径约束、源码摘要）；Apple M4 Metal Validation 下 alpha replay 1165 项检查通过；未启用补丁的渲染器语法编译通过；所有游戏配置头生成通过。动森改写输出与搬迁前一致。此次没有新做地图画面对照。已生成 0.3.48（50）完整 IPA，包含全部 9766 个着色器；全部着色器源码与迁移前逐字一致，ZIP 完整性校验通过。尚未进行本版手机实机验证。

启动页、专属/自定义按键、输入法、数据包、照片保存、音频设置和 Duo 功能保持原实现。本次未整体升级 NX 引擎。
