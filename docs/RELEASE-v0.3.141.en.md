## English

- If the uploader detects a cloud save that was not compared at startup, both saves are preserved until the next launch compares them. A damaged cloud file is backed up before it is replaced.
- Display mode reports the effective present interval. Compute dispatch prepares texture views before encoding so shaders see the updated pixels and Metal can open the encoder safely.
- Improve clock-based waits and update shader translation and shared build tools.
- LiveContainer + SideStore users should install this release's LAN host and allow Local Network access. You can keep using the same patched host if it is already installed. Direct sideloading does not require the LAN host.
