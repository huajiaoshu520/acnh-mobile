# 动森iOS移植优化18-25

起点：原独立优化工作区当前代码快照，0.1.15 / 构建27，含 CPU/内存优化、地图/树叶修复、amiibo 文件导入及等待暂停修复。

代码目录与旧分支独立。`local/data/` 为独立复制的私有运行资源；存档、缓存、日志、编译及 IPA 输出均留在 `local/` 对应子目录。即使底层文件系统使用写时复制，修改后的内容也不会回写来源。Git 共享提交历史，不共享运行数据。

本次仅建立隔离分支，没有宣称已完成 iOS18–25兼容适配，也不更换手机安装包标识。若要在同一手机同时安装两个版本，还需另外配置独立 Bundle ID。

私有 IPA 构建入口：`python tools/build_ios18_25.py`（使用已安装构建依赖的 Python），自动读取本分支版本号并输出到本分支 `local/outputs/`。加 `--show-paths` 可只查看隔离路径。本地测试环境入口为 `local/env.sh`；测试使用 `local/saves/current/`，初始备份为 `local/saves/baseline/`。

## iOS 18 适配候选 0.1.16 / 构建28

工程安装下限改为 iOS 18.0，并在工程级固定 DM_NVN_M3=1，避免直接构建时误用 Metal 4。CPU 编译基线由 apple-a18 改为 armv8.2-a+lse，保留宿主汇编要求的 LSE，不再让编译器生成 A18 专属指令。启用未保护的新系统 API 编译错误检查。未改变分辨率、材质、特效及运行帧率配置。

构建入口现在先把源码复制到 local/build/source，再生成头文件、Xcode 工程和资源，所有构建副作用留在 local/。需要已安装 fontTools 的 Python。

Apple 系统从 iOS 18 跳至 iOS 26，18-25 是保留的分支名称，不代表存在并验证过 iOS 19–25。安装门槛与编译通过不等于真机正常运行或稳定30fps；仍需 iOS 18 真机验证启动、读档、地图、树叶、音频、amiibo .bin 长等待与前后台恢复。暂不支持 .nfc。私有 IPA 不公开上传。

构建28验证：开启系统API可用性检查的 Release 编译通过；IPA 完整性通过；包内 Info.plist 与 Mach-O 最低系统版本均为18.0；未导入 MTL4 符号；amiibo 暂停恢复64轮回归通过。校验报告与 SHA256 保存在 local/outputs/。没有进行手机实测，不宣称已达到稳定30fps。

## A12黑屏修复候选：0.1.19 / 构建31

用户构建28日志末尾：着色器4cc65e10b092ed83_b参数块encodedLength=16、maxAid=0触发FATAL；尚无影片解码记录，不归因为视频解码器。旧实现假定每ID固定8字节。

Apple7之前GPU、实际布局不符或DM_TEST_ARGUMENT_ENCODER启用时，使用MTLArgumentEncoder按真实布局编码缓冲及偏移、贴图和采样器。保留资源用途声明、每次绘制独立存储及同通道复用；现代GPU布局符合时保留直接编码。并非仅移除校验。画质与帧率配置未变，继承相册更新。

验证：Apple M4真实GPU上的16字节单参数绘制、颜色、缓存复用、稀疏及连续混合资源、缓冲偏移、直接/API输出对照通过；iOS Release编译、IPA完整性与包内0.1.19/31及iOS18下限核验通过，无MTL4符号。测试入口tools/test_argument_encoder.py，输出留在local/。A12手机过场及稳定30fps待复测。

## A12紫块与GPU访问错误排查候选：0.1.20 / 构建32

构建31新日志已无之前的参数布局FATAL，场景可显示；首个GPU错误是fence1351/帧1350的PageFault，后续提交被系统忽略。截图出现人物及部分UI紫色块。日志不足以把全部现象唯一归因。

发现并修复具体资源寿命缺陷：mtl_reg_samp替换描述符时立即CFRelease旧采样器；参数块只包含编码后的句柄，不能保证尚在队列中的绘制所用旧采样器仍活着。改为defer_obj_unref，等对应GPU栅栏完成后释放。没有改变画质、帧率或运行配置。

验证：新增旧对象寿命回归在修复前失败、修复后通过（替换后保留，到栅栏后销毁）。Apple M4上的16字节单参数绘制、缓存复用、稀疏及连续混合绑定通过。BC7八种模式与原生GPU逐像素对照最大误差为0。Release编译和IPA完整性通过，包内0.1.20/32、iOS18下限及相册用途说明已核对，无MTL4符号。未进行A12真机复测，不能宣称紫块/GPU错误已全部解决或稳定30fps。
