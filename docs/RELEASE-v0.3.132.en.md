## English

- iPad portrait mode divides the game and companion into equal halves. Original fits the full 16:9 image in the upper half. Adaptive expands the view to fill that half.
- Fixed a hinge capability callback in LiveContainer that caused iPad to use the old split. A real tabletop division still follows the system layout.
- Generic, dedicated and custom touch controls share the actual lower-screen control area. Dragging and resizing keep controls inside that area and clear of the bottom navigation. Existing custom layouts can still be used.
- LiveContainer + SideStore users should install the attached LAN host and allow Local Network access. The same patched host can be reused. Direct sideloads of the game do not require the host.
