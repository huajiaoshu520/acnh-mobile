# Duo 下屏小地图测试版

版本 0.3.47，构建 49。未发布。

仅在 Duo 半折叠上下分区成立时启用下屏地图。游戏画面保持上屏，现有小地图同步到下屏中央，两侧保留控制器。第一版保留上屏原小地图，用于画面对照。它不是独立大地图；跟随游戏原有小地图更新，不能让游戏尚未完成的建筑提前显示为完工。

实现是同一个 Metal 显示命令中的第二次裁切绘制，使用单独的参数表和三份轮换缓冲，避免改变主画面的采样范围；不做 CPU 截图回读。当前裁切范围针对动森 3.0.3 的 16:9 HUD。先用纸质边框四点检测判断小地图是否出现，未检测到则清空下屏地图区域。此判断是原型，雪景、过渡动画、不同 HUD 设置仍可能误判，尚不能当作游戏内部可见状态信号。

验证：iPhone/iPad Release 构建通过；Apple M4 上启用 Metal Validation，检查主画面/地图参数隔离、可见地图采样和隐藏后清空，通过。启动页及原有布局测试通过。没有 Duo 真机，开合和第二个 CAMetalLayer 的显示节奏仍需真机测试。
