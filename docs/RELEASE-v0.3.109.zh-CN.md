# v0.3.109（118）

本次将此前本地完成的界面与竖屏功能一起发布。

- 自适应模式下，时间日期、手机提示、版本信息、加载提示及相关边角指引按扩展后的画面定位；补齐室内布置、输入界面及多处底部提示，修正动画期间的位置跳动和嵌套背景覆盖。
- 修复系统输入法文本提交与重新连接后的输入状态。
- iPad 与具备铰链检测能力的 Duo 竖屏采用上下屏布局：上方保留完整游戏画面，下方显示六页岛屿信息副屏；优化刷新与页面生命周期。
- 自定义按键编辑器识别上述设备的横竖屏。竖屏上方显示游戏预览，下方编辑按键；分别保存 iPad、Duo 竖屏布局，旋转保留编辑草稿，复位只作用于当前布局。

实际同步 14 项官方修复：
- 空顶点流不再阻断几何绘制合批。
- 内存池销毁后的纹理引用安全处理。
- Unity 2020.3 精简 ComputeShader 布局识别。
- 三项重写器修复：寄存器写入识别、跳转表索引与基址覆盖追踪、边界检查后索引改变的拒绝处理。
- SARC 成员名称扫描避免重复处理整个剩余缓冲区。
- 带 ReadOption 的精确文件读取接口。
- 深度纹理作为红色通道视图时的存储复用与通道映射。
- SDK 文件系统卸载后释放挂载表项。
- 奇数显示间隔使用 60 Hz 显示回调。
- NFC 库初始化前的状态返回。
- 编码线程正确记录带选项的深度平面复制，避免复制路径停住。
- 一键构建提前检查游戏所需密钥，缺失时直接说明密钥与对应固件。

保留 IPA 与外置数据包分离、专属控制器、DLC、本地联机、相册及云存档流程。现有兼容数据包可以继续使用。

LiveContainer + SideStore 用户请安装附件的联机宿主并允许本地网络；相同修补版无需重复更新；直接侧载游戏无需宿主。

本机回归和编译不能代替真机验证；iPad/Duo 的旋转、铰链和触控效果仍需设备确认。
