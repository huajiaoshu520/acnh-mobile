# 本地更新 0.3.81（90）

保留 0.3.80（89）的界面、按键、自适应、联机、相册和云存档入口；本版更新按用户授权发布，定时任务仍保持暂停。

## 本次内容

- 显示快照纹理保持驻留，避免提交前被释放。
- 内存保护与纹理池退役的竞态修复。
- Nintendo Pro / Joy-Con 按标签映射面键；其他手柄按位置映射。
- 云存档下载线程创建失败时及时返回，保留下载超时上限。
- 振动句柄只向实际挂载的手柄提供。
- AudioOut 启停使用大栈；旧音频渲染器的系统对象偏移按实际函数确认。
- 老 SDK 图形内存信息大小、缓冲纹理对齐复制及纹理句柄低位解析修复。
- 外接电视／AirPlay 使用官方独立输出，手机保留触控区，电视画面为 16:9；断开恢复原手机布局。实际设备及 LiveContainer 的多场景输出待验证。
- Atmosphère 格式金手指：Mac 提供官方菜单和窗口；iPhone 使用 cheats 文件与开关配置，未新增启动页管理器。默认无代码启用；iPhone 不支持修改签名代码页的金手指。
- 物理输入录制／按帧回放：默认关闭。Documents/env.txt 中 DM_REC=recording.txt 录制；移除后用 DM_KEYS=@recording.txt 回放。回放需匹配构建与起始存档，不保证跨版本一致。

## 验证

Mac 与 iOS 完整编译；游戏启动超过 300 帧后关闭；输入 147、金手指 VM 143、云存档 54、系统通知 49 项检查通过；手柄映射、音频生命周期、内存保护竞态、快照像素、界面比例以及 35 项金手指转换检查通过。电视／AirPlay、多实体手柄与跨设备 iCloud 仍需真机确认。
