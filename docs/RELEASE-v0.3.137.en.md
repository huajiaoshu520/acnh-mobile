## English

- Fix overlap between the left stick and D-pad in the generic landscape layout. The stick uses the NX default position and leaves room for the D-pad when it must avoid a system obstruction.
- Resizing a custom control in the generic landscape layout keeps its default position. Saved custom positions remain in effect.
- LiveContainer + SideStore users should install this release's LAN host and allow Local Network access. You can keep using the same patched host if it is already installed. Direct sideloading does not require the LAN host.
