# v0.3.99（108）

基于已恢复的 build 104 更新，保留原有界面、控制器、外置数据、DLC、LAN 和云存档。

实际同步的官方修复：
- H.264 时间戳重启后的循环播放顺序，以及 Vorbis 长短窗口切换的音频输出长度。
- 文件服务请求释放同核心线程交接，避免存档工作线程和主线程的状态竞态；保留现有事务存档提交与句柄校验。
- 图形查询表自动扩容，避免固定容量丢失条件渲染结果；改进运行中缓冲更新的可见性、同目标渲染延续、深度读写边界及大目标局部区域处理。
- 修正未实现 NVN 调用的重复日志、音频输出设备通知的 SDK 接口名称兼容。
- 离线管线缓存按真实库内容复用；着色器提取缓存和临时 profile 搬迁修复；标准 gzip 输入校验与提取；Unity 6000.3 ComputeShader 布局兼容；构建深度模式取游戏实际调用结果。
- 改写工作进程的信号处理与收尾竞态，避免小任务的退出等待卡住。


同时包含此前本地完成的修复：音频释放通知竞态、解除内存映射后归还页面、Mac 开始游戏后及时关闭启动页、BGRA/BGRX 影片颜色及 Bundle 2 边界校验；自适应装修菜单重影、背景覆盖、渐变层、成品转场和加载装饰布局。角落 HUD 重新定位不在本次范围内。

匹配的既有着色器链与 IPA＋数据包分离流程保留。依赖另一着色器链的翻译器及计算初始化改动未纳入本次范围；没有宣称新增设备运行支持。

通过 LiveContainer + SideStore 运行游戏，请安装发布附件的联机宿主并允许本地网络。相同修补版无需重复安装；直接侧载游戏无需该宿主。

编译与本机测试不等于 iPhone/iPad 真机验证。本轮校验结果保存在本地测试记录中。
