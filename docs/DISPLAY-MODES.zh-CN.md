# iPhone／iPad 画面显示

启动页保存四个选项，下次沿用；默认“自适应”。选择值与运行模式、语言在右侧对齐。

- 自适应：普通宽屏 iPhone 横屏时扩展左右视野，保持人物、建筑及界面比例；iPad、竖屏和折叠姿态沿用现有完整显示布局。iPad 上下扩展尚未实现。
- 原版：保持 16:9，不拉伸、不裁掉边缘。
- 拉伸：填满可用显示区域，比例会改变。
- 裁剪：保持比例放大至填满区域，边缘画面和 UI 可能被裁掉。

扩展补丁只匹配动森 3.0.3 的程序构建，随程序重新改写生效，不修改 RomFS 或现有外置 `.data`。自适应会补偿文字和图标的横向比例，并扩大圆形转场的两侧黑色挡板，保留圆形开口和动画。

专属、通用、自定义按键的位置不随模式改变。Duo 上半区保留独立裁切和下半区按键布局；Mac 的窗口／全屏逻辑不变。

本地 Mac 对照测试使用独立程序与存档副本；编译通过不代表所有 iPhone、所有菜单及所有转场都已验证。
