## English

- Keep conditional rendering enabled or disabled across command submissions on the same NVN queue. Each queue retains its own state.
- Generic landscape touch controls use the NX default positions. On foldable devices, controls move only when a system region obstructs them. Saved custom layouts keep their existing bounds.
- The Mac raw HID backend identifies devices by their I/O Registry ID, so duplicate matching notifications do not take multiple player slots. GameController continues to take priority.
- LiveContainer + SideStore users should install this release's LAN host and allow Local Network access. You can keep using the same patched host if it is already installed. Direct sideloading does not require the LAN host.
